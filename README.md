# ✈️ Flight Booking System

A web-based Flight Booking System built using Python and Django. The application allows users to search flights, select seats, enter passenger details, make demo payments, view e-tickets, and manage their bookings.

## 🚀 Features

- User Registration and Login
- Flight Search
- Flight Results
- Passenger Details
- Seat Selection
- Booking Summary
- Demo Payment System
- E-Ticket Generation
- My Bookings
- Booking Cancellation
- Responsive Web Interface

## 🛠️ Technologies Used

- Python 3.10
- Django 5.2
- Django REST Framework
- PostgreSQL
- HTML5
- CSS3
- JavaScript
